# VIE 0.29.2：通用流程图阅读

本地交付版本，未操作 Git、PR 或 GitHub Releases。

## 已整合的样式

- 默认 A 全景分支：图按真实边分层，不按 nodes 数组串排。并列分支同层，汇合在所有前驱之后，节点支持点击详情。
- 学习模式默认 B 逐步引导：当前节点、声明的可选路径、下一步预览、已访问路径、上一步与重新开始。
- 在图内切换“全景总览 / 逐步引导”。只更换阅读方式，不调用模型、不改写原图关系；保留路径。
- C 对照泳道未作为本次默认实现。

## 通用数据与兼容

原有输入继续有效：

```json
{"type":"visual","kind":"Flow","spec":{"title":"流程","nodes":[{"id":"a","label":"开始","detail":"当前节点说明"},{"id":"b","label":"结束"}],"edges":[{"from":"a","to":"b"}]}}
```

仅新增可选 spec.presentation：overview / guided。显式设置优先于聊天模式；未设置时，Host 根据当前聊天模式把默认样式写入结果，使历史图不随模式切换而改变。旧历史使用新总览渲染器。图形内容仍由模型按主题提供，不需要按学科增加模板。

## 边界与状态

- 通过强连通分量和拓扑层级处理循环与汇合，循环不被删除或改成直线步骤。
- 引导只跟随 edges；分支多于一条时先选择再前进，无出边时停止。不自动运行循环。
- 路径最多记录 64 步，到限后可返回或重开；不会伪造未声明的跳转。
- 多起点可选择起点。切换视图、重新挂载与有效 checkpoint 恢复保留路径；修改图后不再合法的路径会失效。
- 所有文字转义。沿用原生主题、展开焦点管理、Esc 收起。窄屏使用紧凑节点；过宽的横向图或大量并列分支保留字号，在局部区域阅读，可切换逐步引导。

## 同版本修正：升级后的按钮样式与宽分类图

- 修复客户端 apply 在发现固定样式标签后跳过更新的问题。保持一个样式节点，内容变更时刷新 CSS，避免新版 HTML 搭配旧 CSS；重复激活不增加重复标签。
- 对多级宽分类树按真实父子关系分组，条件放进各自的节点卡片，窄屏纵向重排；不再强制将全部叶节点排成一行。所有节点与声明边保留，不复制共享汇合节点，不把循环变成树。
- 带汇合或循环的图继续使用原图结构与逐步引导，避免为了排版改写图的含义。
- 图内切换、选项、步骤和下一步按钮统一样式，补齐点击节点后键盘焦点的保留。
- 新浏览器回归先模拟旧样式残留，再调用实际插件 apply；检查 840/550/390/320px 的节点完整可见、条件标签不相交、按钮尺寸、真实点击和重挂载恢复。旧演示页面直接注入最新 CSS 的路径无法覆盖这个升级缺陷。
- 使用用户会话两张原图在本地重放；私有会话只保存在 .validation，没有放入插件包或公开示例。公开演示增加通用资料校验分类图。
