# VIE 0.29.2 更新说明

## 流程图：全景与逐步阅读

- 按真实连线计算层级，使并列分支同层，汇合节点位于前驱之后；保留循环及独立起点。
- 自动与本聊天启用模式默认全景总览，学习模式默认逐步引导。可用 `spec.presentation` 显式指定 `overview` 或 `guided`。
- 图内可切换视图、选分支、返回和重新开始；只沿声明的边导航，最多记录 64 步，支持本地状态恢复。操作不增加模型请求。
- 宽分类树按实际父分支分组，将条件放入相应节点卡片；窄屏纵向重排。共享汇合或循环仍保留原图结构。
- 修复升级后固定样式节点未刷新，造成按钮和逐步布局使用旧 CSS 的问题；保留节点点击后的键盘焦点。

## 逐题练习与运行稳定性

- 通用 `learning.questions` 支持一组 1–32 题：进度、计分、即时反馈、答案锁定、下一题、最终成绩与重做；兼容旧格式纯测验块合并。
- 出题请求优先完整练习，减少无关概念图和正文提前泄题；解释已有题目仍使用讲解流程。
- 修正意图判断及学习数据入口说明；额度错误给出实际剩余额度，不消耗字段纠错次数。
- iframe 状态消息与 ready/error 分开限量，重置或卸载清理待合并状态，运行报错不会被当成就绪。

## 验证与安装

本地完整验收通过 190 项 Node 测试、11 项浏览器脚本与 7 项宿主脚本。新浏览器回归模拟旧样式残留，再执行真实客户端激活，覆盖 840、550、390 和 320px 下的节点、条件、按钮、交互及恢复。测试期间没有外部模型请求；这些结果不代表模型生成耗时或任意生成内容的科学正确性已获验证。

安装 [0.29.2 插件包](https://github.com/alccs/dsh-visual-intelligence-engine/releases/tag/v0.29.2) 后，请完全退出并重启 Harness，以刷新客户端资源。更新渲染器后，已有原生流程图无需模型重新生成。

公开仓库包含可构建源码与插件产物；私有会话、测试夹具、验证日志和隔离宿主环境不公开。
