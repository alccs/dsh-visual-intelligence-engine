# 0.31.1 修复

本版修复输入栏与内置语音插件的槽位冲突，以及 0.31.0 复查发现的两处图形边界问题。定位、模型设置、图文顺序和 A 风格保持不变。

## 与内置语音共存

VIE 模式选择器迁到 conversation.input.right 列表槽位，使用唯一 id:vie-mode-control。正常输入栏中位于模型选择器之前；内置语音保留原来的 activity 单一槽位。语音展开时，模型选择器和同组控件遵循宿主的临时收起行为。

没有使用 priority 遮蔽另一插件，也不要求关闭语音。模式切换、按聊天保存、服务重连、键盘和菜单样式沿用既有实现。

Issue #1：https://github.com/alccs/dsh-visual-intelligence-engine/issues/1

原先的模式测试使用只追加数组的槽位替身，不能发现 single 槽位重复注册。本版完整宿主回归改为执行已安装官方前端中未经修改的 SlotCore，并使用内置语音插件的注册表达式。验证两种加载顺序、已有其他列表条目、远程连接失效与恢复、模式切换和卸载后的席位清理；也会对实际安装后的 TGZ 重跑。

另从官方发布包核对 issue 使用的 Harness 0.2.1-rc.3：真实槽位内核下，两种注册顺序、各 3 次移除/重连及最终清理均通过。这是槽位级验证，没有启动录音或重启真实桌面应用。

## 有效内容判定

修复完全透明的 SVG 填充、描边和文字被误判为成功；支持检查计算颜色的零 alpha。图形被 SVG 视口或 HTML overflow 容器完全裁出时保持 waiting；部分仍可见的对象与有描边的水平/垂直线继续算有效内容。

采用祖先裁剪区域的交集，测量结果在单次检查中缓存。CSS visibility 的显式子级覆盖按实际浏览器语义处理；祖先的 display:none、opacity:0 仍生效。

这仍是有界的内容证据检查，不是完整 SVG 像素验证器。复杂 mask、clipPath、渐变和遮挡等情况不能据此证明图像完整或知识正确。

## 阶段可见性

visible:true 同时清除目标的内联 display 隐藏与 display="none" 属性，并覆盖自身 visibility 隐藏。visible:false 继续隐藏目标。每次仍从原始主图重建，保证跳步、回退与历史恢复不残留前一阶段状态。

父级 display:none 仍会隐藏其子树，需要显式改变父级状态；不会擅自展开其他分支。

## 验证与交付

新增 browser-0311.mjs 覆盖隐藏形式、反向跳步、恢复、透明画面、完全裁出与部分可见图形。完整回归包含既有浏览器和宿主检查；具体结果、范围、构建指纹和 SHA256 见本地交付清单。

交付使用正式版本 0.31.1，不覆盖 0.31.0。安装本地 TGZ 后完全退出并重启 Harness。线上仓库、npm 与市场不会因本地构建自动更新。
