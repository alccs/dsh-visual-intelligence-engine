# 当前项目总结 · VIE 0.29.0

## 定位

dsh-Visual-Interactive-Engine是DeepSeek Harness的通用图文交互插件。目标是让任何适合视觉表达的问题，都能用图形、交互和正文共同解释。核心分工：模型负责主题内容与必要计算；VIE负责图形渲染、通用控件及本地状态；Harness负责完整文字与会话。

## 主要特点

1. 通用内容：自由SVG/HTML/Canvas/WebGL与结构化图形并存，不用学科白名单限制问题。
2. 统一交互：learning阶段与测验、数据图及通用参数控件减少重复界面代码，主题图形仍可自由组织。
3. 图文阅读流：独立图形按调用位置与Harness正文交替，支持完成后的正文投影、冷历史与局部修图原位替换。
4. 本地计算：按钮、参数和答题反馈在浏览器执行，普通操作无需再次请求模型。
5. 四种模式：自动、本聊天启用、学习模式、关闭，按聊天持久保存；学习模式按需补应用和测试。
6. 渐进生成与修复：完整块预览、字段错误反馈、修订号检查、有限修复预算、失败保留好图。
7. 默认继承模型配置：不强改推理档位或输出额度，默认关闭插件强制超时；减少界面生成负担不等于保证固定生成时间。
8. 可交付工程：双端共享校验、隔离运行、主题和窄屏支持、真实Host与Chrome验证、安装包和源码校验。

## 三条表达路径

| 路径 | 适用内容 | 模型主要提供什么 |
|---|---|---|
| 结构化数据 | 学习阶段、测验、常见数据图 | 图形内容、题目、数据 |
| 声明式图形 | 流程、关系、曲线、时间线、示意与动画 | 节点、关系、表达式和参数 |
| 自由figure | 特殊图形、复杂局部动画或三维说明 | 自包含图形与计算代码 |

已有齿轮、蜗杆、波形等实验属于快捷方式，可以选择使用；它们不决定插件能回答哪些主题。

## 架构

Host、共享契约、Client、隔离图形与存储/交付构成主要层次。[ARCHITECTURE.md](ARCHITECTURE.md)给出数据流图和对应文件。生产插件不引入独立业务服务器，也不内置额外模型供应商；调用模型与渲染正文由Harness承担。

## 能力边界与后续

- 通用结构校验、JS语法通过和iframe ready都不能证明物理、工程或数值结论正确。
- 自定义代码仍可能布局不好、逻辑错误或计算过重；目前没有完整CPU/内存配额隔离和自动领域求解认证。
- 历史图中的错误连接或标注需重新生成或修订，不能靠新布局规则自动推断修正。
- 没有外部模型端到端提速百分比或固定秒数承诺；高推理档位仍可能耗时。
- 通用统一读数卡片、播放/暂停/步进、时间轴与更广的动作绑定是后续方向；已有部分视图内置播放控件，不等于通用播放器体系已完成。

与参考Intelligent UI一致的可采纳方向是自由图形、通用UI组件与共享状态相结合；公开DOM支持这种外部结构观察，服务端内部生成协议仍未得到确认。公开仓库仅保留通用架构与发布说明，不附个人分享页面记录。
