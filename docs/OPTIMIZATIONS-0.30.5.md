# VIE 0.30.5：完整显示图形与 A 式通用组件

本版在 0.30.1 基础上修复图形没有使用正文宽度、右侧内容落入隐藏滚动区域的问题。定位不变：模型自由绘制主题图形，VIE 提供稳定的交互与运行时，完整解释由 Harness 正文渲染。

## 根因与修改

- 外层 `.vie-shell` 原先固定 `max-width:760px`，宽聊天区仍留下大块空白。现在使用宿主提供的可用宽度，并允许 flex/grid 容器正常收缩；不会改变 Harness 正文本身的宽度。
- 静态 SVG 原先为了保证字号至少 11px，自动增加 `min-width` 并取消 `max-width`。当图宽大于 iframe 时，内容进入隐藏滚动条的区域。现在对具有有效 viewBox 的独立静态 SVG 保持比例、完整适配容器，不再为了字号扩大画布。
- 小字仍测量并显示“可展开查看”提示。外层只保留展开/收起，以及有状态图形的复位；不重新加入放大按钮。
- 展开、收起、聊天窗变窄或变宽沿用同一 iframe；布局变化不重置图中状态。

## A 风格组件

用户选定 A，并明确重点是按钮、滑动条等组件。正式实现集中在共享控制层，未移植原型页面的固定布局。

- 按钮：10px 圆角，主操作使用中性色，次操作使用细边框，辅助操作可用文字按钮；常规高度 38px，紧凑操作 32px，粗指针环境使用 44px。
- 滑块：4px 轨道、14px 白色圆点和轻阴影，已填轨道反映实际范围及当前值；输入、复位、共享状态和动画均同步显示。
- 页签、分段选择、下拉、数字输入和开关共享中性颜色、边框和键盘焦点规则。开关保留真实 checkbox 语义与键盘操作。
- 原生参数区、图形外层操作、图内默认 HTML 控件及 SDK 工具栏共用同一份规范；深色模式继承宿主对比关系。图中数据、曲线和状态的语义颜色独立管理。
- `VIE.ui.toolbar` 的每个项及 `set` 支持 `variant: 'primary' | 'secondary' | 'ghost'`，默认 secondary，旧调用继续有效。
- 样式层只更新滑轨填充，不改写业务值，不发送业务事件，不增加模型调用。观察器、监听与待执行帧随视图销毁清理。

自由 figure 中显式自定义的内容 CSS 仍可覆盖默认样式；模型指引要求沿用控件默认外观。规范不强制重排作者的图形布局。

离线演示的 `#controls` 页面使用正式渲染器展示原生与图内组件，可操作并切换深色模式。

## 验证

图形恢复补丁处理两个独立问题：常见的标签 `align` 写法原先会使整图被拒绝；预览切换为最终卡片时，保留的场景存储先更新，旧视图随后挂载，将旧错误回传成修正版错误。现在标签别名使用统一归一化，视图挂载和回调均检查其所属定义，拒绝新脚本时关闭旧消息通道。真实运行错误仍会保留，不能用同一修订的 ready 消息掩盖。

`scripts/browser-render-repair.mjs` 使用独立编写的公开示例，覆盖预览报错、修图后切换卡片、旧回调延迟到达、非法替换、真实错误及再次恢复。`scripts/test-runtime-feedback.mjs` 同时验证修正版 ready 能通过实际 Harness 命令进入下一次系统提示，避免旧错误耗尽修复预算。

新增 `scripts/browser-responsive.mjs`，使用独立编写的公开 SVG 检查宽屏、窄屏、窄聊天面板、扩大面板及展开/收起。断言覆盖卡片宽度、完整 SVG 边界、右侧标签、比例、页面溢出与小字提示。旧行为在修复前能够稳定触发失败。

发布门禁包含 Node 回归、20 组实际 Chrome 检查及 10 组 Harness/安装检查。实际结果以 `docs/validation/release-gate.json` 为准。`browser-controls.mjs` 覆盖原生与隔离组件、真实键盘、局部状态、复位、动画填充、深色模式和宿主样式边界。

## 边界

窄屏中同时显示完整宽图会使文字缩小，展开能使用更多可用空间，但不会把错误的标注、线条或知识内容自动改正确。没有 viewBox 的自定义内容、作者主动裁切的区域及复杂交互布局仍由其内容逻辑决定。本版不改写任意 SVG 的科学几何关系。

更广的优化建议见 [项目定位与后续规划](ROADMAP-0.30.5.md)，其中明确区分本版已实现和后续待做。
