# 0.31.0：减少重复生成，准确反馈内容状态

定位保持为通用可视化与本地交互：模型根据内容自由绘制，VIE 提供控件与运行环境，完整讲解由 Harness 正文渲染。本版沿用 A 风格和展开、复位两个外层操作。

## 混合任务保留操作工具

“运行 npm test，然后用图解释失败原因”“读取 data.csv，用图展示变化”属于实际操作与讲解的组合，保留 Harness 工具，不进入只允许可视化工具的快路径。四种聊天模式均覆盖；纯知识讲解继续使用原流程。分类在本地完成，不增加一次模型请求。

## 一份主图，多阶段变化

learning 增加 baseHtml、可选 baseMobileHtml、readouts，以及阶段 patches/values。共享主图只接受具有稳定对象 ID 的静态 SVG；阶段可改属性、文字和可见性。引擎提供按钮、读数、键盘切换和恢复。

~~~json
{
  "blocks": [{
    "type": "learning",
    "title": "位置变化",
    "baseHtml": "<svg viewBox=\"0 0 300 100\"><circle id=\"point\" cx=\"50\" cy=\"50\" r=\"12\"/></svg>",
    "readouts": [{"id":"position","label":"位置","unit":"px"}],
    "stages": [
      {"label":"开始","values":{"position":50}},
      {"label":"到达","patches":[{"target":"point","attrs":{"cx":250}}],"values":{"position":250}}
    ]
  }]
}
~~~

每次切换都从原始主图重新应用当前阶段，任意跳步不会留下前一阶段的高亮。patches 只允许合法 SVG 属性及本地主图中存在的对象。旧 stages[].html/mobileHtml、自由 figure、Canvas 和 Three.js 路径继续兼容。共享阶段不承担任意 HTML/三维场景差量更新。

## 更小的修订

learning、graphic、chart、visual 的已有数据字段支持 changes[].updates：

~~~json
{
  "visualId":"上一次结果中的ID",
  "baseRevision":1,
  "changes":[{"index":0,"updates":[{"path":"/stages/1/label","value":"完成"}]}]
}
~~~

path 是 JSON Pointer，只替换已有字段，不创建字段或执行代码。每块最多 16 个更新；整体重新校验，失败不会覆盖有效基线。身份、类型、原型与 HTML/JS 字段使用整块替换。自由 figure 继续使用 changes[].block。修订保留原图锚点，过期版本仍被拒绝。

## 内容与运行状态

区分 waiting、preview、ready、error。空容器、骨架、仅有 HTML 标题的外壳不计为内容成功。SVG、文本、控件、加载完成的图片、实际 Canvas 像素和内置三维绘制可提供内容证据；检测无法证明专业正确性。

无法读取的 Canvas 保持未知。自定义绘制完成后可显式调用 VIE.contentReady(canvas)，这属于作者确认，不能解释为自动证明。空白轮询逐步退避至 4 秒，DOM 变化仍可即时触发检查；销毁或失败后清理。等待时显示紧凑状态，避免大块空白。

等待层保留 iframe 的布局与首帧调度，避免“等到绘制才显示、隐藏又阻止绘制”的循环。内置 Canvas 与三维可以先绘制一次初始状态；后续离屏更新和动画仍暂停。错误卡片也保留图形的可测量布局，修正后重新确认真实内容。

预览时间、就绪时间和绘制时间属于当前加载/修订。等待和错误不携带成功耗时；离屏不冒充可见。只读静态回退不清除原失败。源、修订、窗口及通道校验继续有效。

## 布局、控件与诊断

布局警告可携带稳定对象 ID、短标签、边界、相关对象和视口；最多 4 条、合计 2600 UTF-8 字节，只作为数据传递，不自动改变几何或触发请求。重复问题不因边界略有变化反复回传。它是启发式提示，无法验证连线语义、坐标或学科事实。

图内默认控件样式在模型 CSS 后应用，并限定在运行时根范围；普通 button 样式不会覆盖工具栏皮肤。iframe 内 Escape 通过已校验通道关闭展开，焦点回到外层展开按钮。
