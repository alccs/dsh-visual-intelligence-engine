# 0.31.0 验证范围

本版使用 Node.js 24、本地 Chrome 和隔离 Harness 环境验证；不改动真实 desktop profile。详细测试数量与验证指纹由本地交付 manifest.json 记录。

## 参数体积

运行 node scripts/measure-stages.mjs 可以复现以下比较。它比较 0.31.0 中两种等价输入的 JSON UTF-8 字节，不是不同模型或旧版本的端到端 A/B。

| 示例 | 完整重复输入 | 共享/局部输入 | 减少 |
| --- | ---: | ---: | ---: |
| 同一主图的三个阶段 | 3367 B | 1876 B | 44.28% |
| 同一学习图只修改一个标签 | 1891 B | 126 B | 93.34% |

示例覆盖同一套几何、阶段文字与读数，体积比例随内容复杂度变化。几何越少、阶段越少，收益可能越小；自由 JS 整块替换不适用字段更新。

相比基线 83ecf05，学习指引由 926 个字符降为 620 个，入口仍为 214 个；主工具因补充共享阶段与修订契约，由 3367 增为 3571 个字符。字符数不是 tokenizer 的 token 数。本版增加检查和协议支持，未压缩渲染器代码体积；构建实际字节见 BUILD-METRICS.json。

## 软件回归

- Node：共享阶段输入/兼容、字段修订/失败回滚、混合任务路由、内容证据、状态与对象诊断、公开统计/缺失 usage，以及既有回归。
- Chrome：共享阶段跳步/回退、读数、恢复/复位、iframe Escape/焦点、空白与延迟 Canvas、CSS 优先级、布局证据、窄屏；既有图文顺序、历史恢复、二维/三维和控件回归继续执行。
- 真实 Harness 模块：工具 schema、四种聊天模式下的混合任务、运行状态到 Commands 再到下一次 prompt、隔离安装与包内 Client/Host 一致性。
- 公开源码：白名单文件分发，在独立目录重建并执行公开检查；安装包与源码归档扫描本地路径、凭据和私有会话标识。

## 未测项目

没有发起外部模型请求，也未完成同模型、同题、同参数的真实生成速度对照。因此不声称首图降低 25%、token 降低 20% 或优于其他插件。48 题真实模型任务与保留题仍可用于后续评测；新增公开统计用于实际采样。

浏览器验证使用真实渲染器和脚本化模型结果，宿主接入使用真实 Harness 模块与隔离日志适配器；这些结果不等于完整 Electron GUI 的人工验收，也不能证明任意生成知识内容正确。
